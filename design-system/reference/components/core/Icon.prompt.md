Monochrome technical glyph from the Lucide outline set; use for every UI icon in SADA 3D.

```jsx
<Icon name="ruler" size={16} />
```

Icons inherit `currentColor`. Sizes: 14 (inline/metadata), 16 (UI default), 20 (nav, buttons lg), 24 (feature). Never tint an icon orange unless the element it labels is active/selected.
