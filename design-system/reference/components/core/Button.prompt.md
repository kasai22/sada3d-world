The SADA 3D action control — sharp (3px), uppercase, technical letter-spacing; never pill-shaped.

```jsx
<Button variant="primary" size="lg" iconRight="arrow-right">Start Printing</Button>
```

Variants: primary (orange gradient CTA — one per view), secondary (titanium outline), tertiary (filled carbon), ghost, technical (orange outline, for engineering panels), destructive. States: `loading`, `success`, `disabled`.
